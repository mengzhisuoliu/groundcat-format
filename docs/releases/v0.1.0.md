# 走地猫 v0.1.0

## 首先，致敬原作者

走地猫基于 [LaoFeng-mouse/flyingmouse-format](https://github.com/LaoFeng-mouse/flyingmouse-format) 的 **FlyingMouse Format v0.5.0** 改造而来。

感谢 **LaoFeng（LaoFeng-mouse）** 开源完整的离线转换核心与工程基础。本版本保留其核心转换能力，并重新设计了产品名称、视觉界面、安装体验与结果保存流程。走地猫是独立的社区衍生版本，不代表原作者官方发布；项目继续遵循 MIT License，原版权和许可声明完整保留。

## 本版内容

- 极简三步界面：选择文件、选择格式、开始转换。
- 转换结果自动写入源文件所在目录。
- 新增“打开所在文件夹”直达按钮。
- 同名文件自动追加序号，绝不覆盖已有文件。
- 单页 PDF 转 PNG/JPG 直接输出图片；多页 PDF 继续使用 ZIP，避免丢页。
- 应用和快捷方式名为“走地猫”，默认安装目录为 `C:\Program Files\groundcat`。
- 支持图片、文本、Office/WPS、PDF、OCR、音视频、ZIP 与批量转换。
